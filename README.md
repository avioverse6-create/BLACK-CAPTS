# BLACK-CAPTS

A small Android-oriented 3D winter-town prototype made with Godot 4.

## Current prototype
- Compact snowy blockout map with one road and three building placeholders.
- Procedural snowfall and simple low-poly placeholder trees.
- Third-person player movement with on-screen directional controls.
- Three wandering NPC placeholders.

## Run
Open this folder in Godot 4.4 or newer and run the project.

## Android APK
The project files are in place, but an APK has not been built or tested yet. Android export requires matching Godot export templates and Android SDK/JDK configuration. Follow the [official Godot Android export guide](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html).

## Assets and licensing
The current scene uses temporary primitive placeholders, not final character or building models. Only add assets with a clear license that permits use in this project. Leaked or ripped game files are not included.
